#### A. Encryption
(+) `SSL/TLS` can be set for `data in transit`, can set it to be mandatory.
(+) RDS support `EBS volume encryption` using KMS, where we can select AWS or customer managed CMK generates `data keys`
(+) Data keys used for encryption operations
==> Storage, Logs, Snapshots and RR are encrypted
(+) RDS MSSQL and RDS Oracle support `Transparent Data Encryption`, where encryption handled within the DB engine not the host.
(+) RDS Oracle supports integration with `CloudHSM` where we controls the key.
