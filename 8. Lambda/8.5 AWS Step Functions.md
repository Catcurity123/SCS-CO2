#### A. What is it
(+) Design to fix product limitation of Lambda. Lambda is a `FaaS` 
(+) Lambda has execution time of 15-minute max and can be chained together, but the runtime environment of Lambda are `stateless`
(+) Step Functions allow us to create a `State Machine` which is a serverless workflow with `Start -> States -> End`.
(+) States are things which occur in a step.
(+) It has a maximum duration of 1 year, with `Standard` workflow and `Express` workflow.
(+) The state machine use `IAM role` for permissions, and it uses Amazon States Language (ASL) - JSON Template.

###### What is a State?
(+) `Succeed` and `Fail` State, where a workflow either succeed or fail
(+) `Wait`, where the workflow wait for a period of time.
(+) `Choice`, which allow to change a workflow to a different workflow based on option
(+) `Parallel`, which allow more workflow to work on the same items
(+) `Map`, which input is a map of items and work on each of the item
(+) `Task`, which is the actual action for the function, it can be send notification to SES, or send email to user.
