#### A. What is it
(+) CloudWatch Events and EventBridge have visibility over events generated by supported AWS services within an account.
(+) They are created to do: if `X` happens, or at `Y` time(s) ... do `Z`
(+) EventBridge is CloudWatch Events v2
(+) It has a default event bus for the account. In CloudWatch Events, we only have 1 event bus, and it is not exposed to the user. EventBridge can have additional event busses.
(+) We have `Event Pattern Rule` and `Schedule Rule` which will be routed to a `Target` which can be Lambda.
