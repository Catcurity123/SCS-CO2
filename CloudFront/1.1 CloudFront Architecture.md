#### A. What is CloudFront
(+) CloudFront is content-delivery network (CDN), it is used to deliver contents to the users by using caching and global edge network.

###### There are a few terms about CloudFront
(+) `Origin`: The source location of a content, it could be `S3 Origin`, or a `Custom Origin`. 
(+) `Distribution`: The `configuration` unit of CloudFront
(+) `Edge Location`: Local cache of your data. They are smaller than Region, they are used for caching of storing data
(+) `Regional Edge Cache`: larger than `Edge location`, Larger version of an edge location. They provide another layer of caching that is large but less frequently access.

#### B. Cloud Front Architecture
(+) CloudFront is used for download-object only, any upload goes directly to the origin.

#### C. AWS Certificate Manager (ACM)
(+) ACM lets you run a public or private Certificate Authority (CA)
(+) Private CA - Applications need to trust your private CA
(+) Public CA - Browsers trust a list of providers, which can trust other providers.
(+) ACM can generate or import Certificates.
(+) If `generate`, it can `automatically renew`
(+) If `imported`, you are `responsible for renewal`
(+) Certificates can be deployed out to supported services
(+) `Supported AWS Services ONLY` (e.g. CloudFront and ALBs, `NOT EC2`)

(+) ACM is a regional service, certs cannot leave the region they are generated or imported in, so to use a cert with an ALB in `ap-southeast-2` you need a cert in ACM in `ap-southeast-2`
==> Global Services such as CloudFront `operates as though within us-east-1`
====> So when we want to use `ACM` for `CloudFront`, we need to deploy ACM in `us-east-1` or else it wont work.

#### D. CloudFront and SSL
(+) CloudFront has Default Domain Name (CNAME), we can configure SSL Suported by default using `*.cloudfront.net` cert.
(+) Alternate Domain Name (CNAMES) e.g. cdn.catagram... must verify ownership (optionally HTTPS) using a matching certificate.
(+) The certificate must be generated or imported in ACM `in us-east-1`
(+) There are 2 SSL Connections: `Viewer => CloudFront` and `CloudFront => Origin`, both of them need valid public certificates (and intermediate certs if any)
